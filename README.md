# SAVT Assist 📱⚙️

Официальное мобильное приложение **SAVT Assist** для мониторинга и обслуживания шкафов управления (ШУ), управления проектами автоматизации, работы с эксплуатационной документацией и взаимодействия с сервисной поддержкой SAVT.

---

## 🚀 Основные возможности

### 1. Управление шкафами (ШУ) и проектами
* **Быстрое добавление**: сканирование QR-кодов или переход по глубоким ссылкам (`savt://project/...`, `savt://cabinet/...`).
* **Закрепление избранных**: возможность закреплять приоритетные шкафы и проекты вверху списка (`pin/unpin`).
* **Телеметрия в реальном времени**: опрос состояния датчиков, регистров и журнал аварий/предупреждений.
* **Управление доступом**: выход из проектов, удаление персонально добавленных шкафов.

### 2. Документация и схемы
* Просмотр и загрузка технической документации (паспорта, принципиальные электросхемы, карты регистров Modbus, руководства по эксплуатации).
* Встроенный оффлайн-кэш для быстрого открытия сохранённых файлов на выезде.
* Формирование запросов на доступ к закрытым документам.

### 3. Техническая поддержка и чаты
* Диалоги по конкретным проектам, отдельным шкафам или прямая линия с дежурным оператором/инженером.
* Передача фото, видео, вложений документов, аудиосообщений и координат геолокации.
* Редактор изображений (разметка и рисование поверх фото перед отправкой).
* Live-синхронизация и очередь отправки при нестабильном интернет-соединении.

### 4. Сервисные заявки и рекламации
* Подача заявок на гарантийное и сервисное обслуживание.
* Оформление рекламаций с фото- и видеофиксацией дефектов.
* Отслеживание истории, статусов и комментариев специалистов.

## 🛠 Технологический стек

* **Фреймворк**: [Flutter](https://flutter.dev) (Dart 3.x)
* **Сетевой уровень**: [Dio](https://pub.dev/packages/dio) с интерцепторами авторизации и повторных попыток
* **Управление состоянием**: Provider / Stateful lifecycle
* **Локальное хранилище**: SharedPreferences, кэширование файлов и данных
* **Мультимедиа и периферия**: Mobile Scanner (QR), Camera, Audio Recorder / Audio Player, OpenFile
* **Платформа**: Android (релиз подготовлен для Google Play Console)

## 🏁 Начало работы

### Требования
* Flutter SDK `>= 3.22` (канал stable)
* Android SDK (API level 24+)
* Java/JDK 17

### Установка и запуск

1. Перейдите в каталог проекта:
   ```bash
   cd savt_control_panel
   ```

2. Установите зависимости:
   ```bash
   flutter pub get
   ```

3. Запустите тесты:
   ```bash
   flutter test
   ```

4. Запуск в режиме разработки:
   ```bash
   flutter run
   ```

## 📦 Сборка релизных пакетов

### Android App Bundle (для публикации в Google Play)
```bash
flutter build appbundle --release
```
Файл бандла будет расположен в:  
`build/app/outputs/bundle/release/app-release.aab`

### Автономный APK
```bash
flutter build apk --release
```
Файл APK будет расположен в:  
`build/app/outputs/flutter-apk/app-release.apk`
